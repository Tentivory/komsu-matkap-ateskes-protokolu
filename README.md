# Komşu Matkap Ateşkes Protokolü

> **Resmî statü:** Bu depo bir yazılım değildir. Bu depo bir **sınır anlaşmasıdır**.
> Sınır, sizin salonunuz ile komşunuzun salonu arasındaki 12 santimetrelik beton şerittir.

## 1. Kuruluş gerekçesi (son derece ciddi)

Tarih, büyük savaşları top ve antlaşmayla hatırlar. Apartmanlar ise matkap ve "birazdan biter" cümlesiyle hatırlar.

Bu protokol şunu kabul eder:

1. Matkap bir inşaat aleti değildir; **tek taraflı dış politika aracıdır**.
2. "Küçük bir vida" ifadesi, diplomatik literatürde **sınırsız operasyon** anlamına gelir.
3. Duvar tarafsızdır. Duvarın rengi siyasi görüş bildirmez. (Çatlaklar bildirebilir.)
4. Hiçbir ateşkes, matkabın kablosu prize takılıyken gerçek ateşkes sayılmaz. Yine de imzalarız.

## 2. Kurulum

```bash
git clone https://github.com/Tentivory/komsu-matkap-ateskes-protokolu.git
cd komsu-matkap-ateskes-protokolu
python3 ateskes.py
```

Bağımlılık yoktur. Çünkü barışın da olmamalıdır; herkes kendi kulağını getirir.

## 3. Ne yapar?

- Beş tur diplomatik nota basar.
- Rastgele bir ateşkes teklifi önerir.
- Bir karar açıklar.
- Matkabı **asla** durdurmaz.
- Sizi biraz daha az yalnız, biraz daha çok evraklı bırakır.

Bu bir özelliktir. Şikayet dilekçesi Issues sekmesine yazılır; dilekçe de titreşir.
